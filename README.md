# Pinaura Website

Static one-page website for Pinaura, a commercial scenting and air quality brand.

## Local Preview

Open `index.html` in a browser, or serve this folder with any static server.

## Contact Form Setup

The form is wired for Web3Forms:

1. Create a free access key at `https://web3forms.com/`.
2. In `index.html`, replace `YOUR_WEB3FORMS_ACCESS_KEY` with the real key.
3. Update `hello@pinaura.com` to the business email address.

Until the key is replaced, the form shows a setup message and does not submit.

## Cloudflare Pages Deployment

1. Push this repository to GitHub.
2. In Cloudflare Pages, create a project from the repository.
3. Use no build command and `/` as the output directory.
4. Add the custom domain after purchase.
5. Cloudflare Pages will provide HTTPS automatically.

## Editable Placeholders

- `[Region / Service Area]`
- `hello@pinaura.com`
- family story copy
- product descriptions, pricing, and photos
